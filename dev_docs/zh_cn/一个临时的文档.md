## 模式标志

### 语法

| 语法 | 说明 |
|------|------|
| `(?i)` | 启用大小写不敏感 |
| `(?-i)` | 关闭大小写不敏感 |
| `(?im)` | 同时启用 i 和 m |
| `(?i-m)` | 启用 i，关闭 m |
| `(?i:exp)` | 仅在分组内启用 i |
| `(?i-m:exp)` | 仅在分组内启用/关闭指定标志 |

### 可用标志

| 标志 | 作用 |
|------|------|
| `i` | Unicode 大小写不敏感匹配 |
| `m` | 多行模式，`^` 和 `$` 匹配行边界 |
| `s` | 允许 `.` 匹配 `\n` |
| `R` | CRLF 模式，配合 `m` 识别 `\r\n` |
| `U` | 交换贪婪和懒惰的默认行为 |
| `u` | Unicode 模式（默认开启） |
| `x` | 扩展模式，忽略空白和行注释 |

### 额外提示

- 扩展模式 `x` 会忽略字符类外的空白，匹配空格需使用 `\ ` 或 `\x20`。
- 关闭 Unicode 模式 `(?-u:\w)` 可获得 ASCII 语义的 `\w`、`\d`、`\s`、`\b`。

## 不支持的功能

| 功能 | 常见写法 |
|------|----------|
| 正向先行断言 | `(?=exp)` |
| 负向先行断言 | `(?!exp)` |
| 正向后行断言 | `(?<=exp)` |
| 负向后行断言 | `(?<!exp)` |
| 反向引用 | `\1`、`\2`、`\k<name>` |
| 递归/子程序调用 | `(?R)`、`(?1)` |
| 条件表达式 | `(?(condition)yes\|no)` |
| 原子分组 | `(?>exp)` |
| 占有量词 | `*+`、`++`、`?+` |
| 任意字形簇 | `\X` |
| 字面量引用 | `\Q...\E` |
| 其他锚点 | `\G`、`\Z` |
