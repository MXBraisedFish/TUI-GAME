# char 库

## 基本库说明

`char` 提供边框字符集与 ASCII 字符数组常量。游戏与屏保会话均可使用。库表为只读。边框字符表可直接用于 `draw.stroke_rect` 的 `border_char` 参数；ASCII 数组用于字符枚举与集合运算。

## 目录

### 常量

| 常量名 | 说明 |
| ------ | ---- |
| `char.LINE` | 单线边框字符表 |
| `char.BOLD_LINE` | 粗线边框字符表 |
| `char.DOUBLE_LINE` | 双线边框字符表 |
| `char.ROUNDED_LINE` | 圆角线边框字符表 |
| `char.ASCII_NUMBER` | `"0"`~`"9"` 字符数组 |
| `char.ASCII_LOWERCASE` | `"a"`~`"z"` 字符数组 |
| `char.ASCII_UPPERCASE` | `"A"`~`"Z"` 字符数组 |
| `char.ASCII_LETTER` | 大小写字母字符数组 |
| `char.ASCII_CHARACTER` | ASCII 符号字符数组 |
| `char.ASCII` | 数字+字母+符号全量字符数组 |

### 方法

本库无方法。

## 常量

### `LINE`

| 项目 | 内容 |
| ---- | ---- |
| **可应用参数** | `draw.stroke_rect` 的 `border_char` 参数 |
| **作用** | 单线边框：由 `─`、`┌`、`│`、`└`、`┘`、`┐`、`├`、`┴`、`┤`、`┬`、`┼` 等组成 |
| **额外补充** | 只读表；键为 `top`、`left_top`、`left`、`left_bottom`、`bottom`、`right_bottom`、`right`、`right_top`、`t_left`、`t_bottom`、`t_right`、`t_top`、`center` |

---

### `BOLD_LINE`

| 项目 | 内容 |
| ---- | ---- |
| **可应用参数** | `draw.stroke_rect` 的 `border_char` 参数 |

| **额外补充** | 只读表；键与 `LINE` 相同 |

---

| **额外补充** | 只读表；键与 `LINE` 相同 |

---

---

### `ASCII_NUMBER`

| 项目 | 内容 |
| ---- | ---- |

| **作用** | 数字字符数组 `"0"`~`"9"`（共 10 项） |
| **额外补充** | 只读数组；索引 `1..10` |

---

| **作用** | 小写字母字符数组 `"a"`~`"z"`（共 26 项） |

| ---- | ---- |

| **作用** | 大写字母字符数组 `"A"`~`"Z"`（共 26 项） |

### `ASCII_LETTER`

| 项目 | 内容 |
| ---- | ---- |
| **可应用参数** | 直接作为字符数组遍历 |
| **作用** | 全部大小写字母（共 52 项，小写在前） |
| **额外补充** | 只读数组；`ASCII_LOWERCASE` 与 `ASCII_UPPERCASE` 的合并 |

---

### `ASCII_CHARACTER`

| 项目 | 内容 |
| ---- | ---- |
| **可应用参数** | 直接作为字符数组遍历 |
| **作用** | ASCII 符号字符数组（共 32 项） |
| **额外补充** | 只读数组；符号集为 `!"#$%&'()*+,-./:;<=>?@[\]^_\`{|}~` |

---

### `ASCII`

| 项目 | 内容 |
| ---- | ---- |
| **可应用参数** | 直接作为字符数组遍历 |
| **作用** | 全量可打印 ASCII 字符（共 94 项，数字、字母、符号依次排列） |
| **额外补充** | 只读数组；`ASCII_NUMBER`、`ASCII_LOWERCASE`、`ASCII_UPPERCASE`、`ASCII_CHARACTER` 的合并 |
