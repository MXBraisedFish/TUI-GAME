# base 库

## 基本库说明

`base` 提供 Lua 基础值操作，包含迭代器、类型转换与保护性读取。游戏与屏保会话均可使用。库表为只读，不注入同名全局函数。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `base.ipairs(table)` | 按整数键 `1..n` 遍历数组部分 |
| `base.pairs(table)` | 遍历表全部键值对 |
| `base.next{...}` | 顺序返回下一组键值 |
| `base.select{...}` | 按位置选取值或返回数量 |
| `base.rawequal{...}` | 不经元方法比较两值 |
| `base.rawlen(value)` | 字符串字节数 / 表数组长度 |
| `base.tonumber{...}` | 数值转换 |
| `base.tostring(value)` | 安全字符串化 |
| `base.type(value)` | 返回值的类型名 |

| ------ | ---- | ---- | ------ | ---- | -------- |
| `table` | table | 是 | — | 要遍历的表 | 可为只读库表 |
| `index` | any | 否 | `nil` | 当前键 | 传入 `nil` 从头开始 |

- **方法返回**：

| 返回值名 | 类型 | 说明 | 额外补充 |
| -------- | ---- | ---- | -------- |
| `key` | any | 下一组键 | 遍历结束为 `nil` |
| `value` | any | 下一组值 | 遍历结束为 `nil` |


- **等价于原版**：Lua 5.4 全局函数 `next`
