# event 库

## 基本库说明

`event` 提供事件处理：跳过当前动作与清空动作队列。**仅游戏会话且关闭安全模式时可用**，屏保会话或安全模式下调用被忽略。库表为只读。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `event.skip_action()` | 跳过当前动作 |
| `event.clear_action()` | 清空动作队列 |

## 方法

### `skip_action`

- **方法作用**：请求宿主跳过本次输入动作的处理。
- **方法要求**：仅游戏脚本、关闭安全模式
- **方法参数**：无参数。

- **方法返回**：无返回值。

