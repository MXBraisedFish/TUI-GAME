# math 库

## 基本库说明

`math` 提供数学运算与数学常量，包括三角函数、对数、取整、组合数等。游戏与屏保会话均可使用。所有方法要求输入为**有限数**，计算结果为非有限数时抛错。库表为只读。

## 目录

### 常量

| 常量名 | 说明 |
| ------ | ---- |
| `math.PI` | 圆周率 π |
| `math.E` | 自然常数 e |
| `math.POSITIVE_INFINITE` | 正无穷 |
| `math.INFINITE` | 正无穷（`POSITIVE_INFINITE` 别名） |
| `math.NEGATIVE_INFINITE` | 负无穷 |
| `math.DEG` | 弧度转角度系数 `180/π` |
| `math.RAD` | 角度转弧度系数 `π/180` |
| `math.MAX_INTEGER` | 最大整数 `2^63-1` |
| `math.MIN_INTEGER` | 最小整数 `-2^63` |
