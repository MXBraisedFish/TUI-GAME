# game 库

## 基本库说明

`game` 提供游戏生命周期控制：退出游戏与触发保存。**仅游戏会话可用**，屏保会话中调用被忽略。库表为只读。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `game.exit_game()` | 退出当前游戏 |
| `game.save_game()` | 触发保存游戏 |
| `game.save_best()` | 触发保存最高分 |

## 方法
