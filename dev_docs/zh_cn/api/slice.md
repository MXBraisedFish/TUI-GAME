# slice 库

## 基本库说明

`slice` 提供图层切片对象管理：创建、修改尺寸与图层层级、查询，以及将切片绘制到画布。游戏与屏保会话均可使用，所有方法均无前置要求。库表为只读。多参数方法使用**命名参数表**。

> 切片对象以 ID（字符串）标识，如 `"slice_001"`。图层层级 `layer` 数值越大越靠上，默认 `0`。宽度/高度参数可传数值，也可传 `slice.*_P` 百分比常量（相对 BASE 图层切片宽/高）。综合使用示例见文末。

## 目录

### 常量

> 所有值均向下取整

| 常量名          | 说明                 |
| ------------ | ------------------ |
| `slice.10P`  | BASE 图层切片宽或高的 10%  |
| `slice.25P`  | BASE 图层切片宽或高的 25%  |
| `slice.33P`  | BASE 图层切片宽或高的 33%  |
| `slice.50P`  | BASE 图层切片宽或高的 50%  |
| `slice.66P`  | BASE 图层切片宽或高的 66%  |
| `slice.75P`  | BASE 图层切片宽或高的 75%  |
| `slice.100P` | BASE 图层切片宽或高的 100% |

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `slice.create{...}` | 创建图层切片对象，返回切片对象 ID |
| `slice.delete(id)` | 删除指定切片对象 |
| `slice.clear()` | 删除所有切片对象 |
| `slice.exists(id)` | 检查切片对象是否存在 |
| `slice.set_size{...}` | 修改切片对象的宽度和高度 |
| `slice.set_width{...}` | 修改切片对象的宽度 |
| `slice.set_height{...}` | 修改切片对象的高度 |
| `slice.set_layer{...}` | 修改切片对象的图层层级 |
| `slice.get_width(id)` | 返回切片对象的宽度 |
| `slice.get_height(id)` | 返回切片对象的高度 |
| `slice.get_layer(id)` | 返回切片对象的图层层级 |
| `slice.get_info(id)` | 返回切片对象的完整信息表 |
| `slice.list()` | 返回所有切片对象 ID 的数组 |
| `slice.list_by_layer()` | 按图层层级从低到高返回全部信息表 |
| `slice.count()` | 返回当前切片对象的总数 |
| `slice.draw{...}` | 将切片绘制在画布指定位置 |
