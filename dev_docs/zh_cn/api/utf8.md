# utf8 库

## 基本库说明

`utf8` 提供 UTF-8 字符串处理。

## 目录

### 方法

| 方法名                        | 说明                       |
| ----------------------------- | -------------------------- |
| `utf8.len(text)`              | 返回字符数                 |
| `utf8.byte_len(text)`         | 返回字节数                 |
| `utf8.is_ascii(text)`         | 判断是否全为 ASCII         |
| `utf8.codepoint_to_char{...}` | 码点序列转字符串           |
| `utf8.ascii_to_char{...}`     | ASCII 码序列转字符串       |
| `utf8.char_to_codepoint{...}` | 字符转码点                 |
| `utf8.char_to_ascii{...}`     | 字符转 ASCII 码            |
| `utf8.char_position{...}`     | 定位第 N 个字符的字节位置  |
| `utf8.codepoints(text)`       | 遍历全部码点               |
| `utf8.next{...}`              | 返回指定位置后的下一个字符 |

```lua

```


### 额外补充

- 返回值表结构如下：

```lua
{
  [1] = ...,
  [2] = ...,
  ...
  [x] = ...,
  n = x
} -- 共有 x+1 个元素，所有返回值连续排序，最后 n 为返回值个数
```

## `next`

获取字符串中指定字节位置之后的下一个字节起始位置和 Unicode 码点。

### 调用

```lua
-- 表参数
utf8.next{}
```

### 参数

| 参数名 | 类型          | 必填 | 默认值 | 说明                                                      |
| ------ | ------------- | ---- | ------ | --------------------------------------------------------- |
| `text` | string        | 是   | -      | 目标字符串                                                |
| `pos`  | integer / nil | 否   | `nil`  | 当前指定字节位置；省略或传入nil时从字符串的第一个字符开始 |

### 返回

**找到下一个元素时**，返回一个对象表。

| 返回值名    | 类型    | 说明                      |
| ----------- | ------- | ------------------------- |
| `codepoint` | integer | 下一个字符的 Unicode 码点 |
| `position`  | integer | 下一个字符的字节起始位置  |

**没有后续元素时**，直接返回一个值。

| 类型 | 说明       |
| ---- | ---------- |
| nil  | 无后续元素 |
