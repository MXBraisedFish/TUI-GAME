# table 库

## 基本库说明

`table` 提供表操作：拼接、插入、移动、打包、删除、排序与展开。游戏与屏保会话均可使用。库表为只读。写入类方法（`insert`、`remove`、`sort`、`move` 目标）要求目标表**可写**，传入只读库表会报错。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `table.concat{...}` | 拼接数组元素为字符串 |
| `table.insert{...}` | 插入元素 |
| `table.move{...}` | 移动数组元素 |
| `table.pack{...}` | 打包为数组表 |
| `table.remove{...}` | 删除并返回元素 |
| `table.sort{...}` | 原地排序 |
| `table.unpack{...}` | 展开数组 |

## 方法

### `concat`

- **方法作用**：拼接数组中的字符串与数字元素，返回结果字符串。
- **方法要求**：无
- **方法参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 | 额外补充 |
| ------ | ---- | ---- | ------ | ---- | -------- |
| `table` | table | 是 | — | 源数组 | 只含字符串或数字，可为只读表 |
| `separator` | string | 否 | `""` | 元素间的分隔符 | — |
| `start` | integer | 否 | `1` | 起始索引 | 1 起始 |
| `finish` | integer | 否 | 数组长度 | 结束索引 | 默认到数组末尾 |

- **方法返回**：

| 返回值名 | 类型 | 说明 | 额外补充 |
| -------- | ---- | ---- | -------- |
| `result` | string | 拼接结果 | 含非法类型元素报错；结果超 1 MiB 报错 |
