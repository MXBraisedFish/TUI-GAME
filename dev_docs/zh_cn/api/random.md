# random 库

## 基本库说明

`random` 提供随机数生成：直接调用（`randint`/`randfloat`）与生成器对象管理（创建、参数修改、查询）。游戏与屏保会话均可使用，所有方法均无前置要求。库表为只读。多参数方法使用**命名参数表**。

> 生成器对象以 ID（字符串）标识，如 `"rng_001"`。`random.generate` 每次调用会使该生成器的步进数 `step` 自增。综合使用示例见文末「使用示例」。

## 目录

### 常量

| 常量名 | 说明 |
| ------ | ---- |
| `random.INT` | 整数类型随机数生成器 |
| `random.FLOAT` | 浮点数类型随机数生成器 |

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `random.randint{...}` | 直接生成 `[min, max]` 区间整数 |
| `random.randfloat{...}` | 直接生成 `[min, max]` 区间浮点数 |
| `random.create{...}` | 创建生成器，返回生成器 ID |
| `random.delete(id)` | 删除指定生成器 |
| `random.clear()` | 删除所有生成器 |
| `random.list()` | 返回所有生成器 ID 的数组 |
| `random.count()` | 返回当前生成器的总数 |
| `random.generate(id)` | 用指定生成器生成一个随机数 |
| `random.set_params{...}` | 修改生成器的参数 |
| `random.set_type{...}` | 修改生成器的类型 |
| `random.set_range{...}` | 修改生成器的随机区间 |
| `random.set_seed{...}` | 修改生成器的种子 |
| `random.set_step{...}` | 修改生成器的步进数 |
| `random.get_type(id)` | 查询生成器的类型 |
| `random.get_range(id)` | 查询生成器的随机区间 |
| `random.get_seed(id)` | 查询生成器的种子 |
| `random.get_step(id)` | 查询生成器当前的步进数 |
| `random.get_info(id)` | 查询生成器的完整信息 |
| `random.exists(id)` | 检查生成器是否存在 |

## 使用示例

```lua
-- 创建生成器
local id = random.create{
  type = random.INT,
  min = 1,
  max = 10,
  seed = 12345,
  step = 0,
}

-- 生成几个数，步进增加
random.generate(id)  -- 步进变为 1
random.generate(id)  -- 步进变为 2

-- 查询
print(random.get_type(id))        -- "int"
local min, max = random.get_range(id)  -- 1, 10
print(min, max)
print(random.get_seed(id))        -- 12345
print(random.get_step(id))        -- 2

-- 完整信息
local info = random.get_info(id)
-- {
--   id = "rng_001",
--   type = "int",
--   min = 1,
--   max = 10,
--   seed = 12345,
--   step = 2
-- }

-- 检查存在
print(random.exists(id))  -- true
random.delete(id)
print(random.exists(id))  -- false
```
