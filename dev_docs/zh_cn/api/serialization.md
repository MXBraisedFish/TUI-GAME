# serialization 库

## 基本库说明

`serialization` 提供多格式序列化与反序列化：JSON、CSV、YAML、TOML、INI、XML，以及二进制打包/解包。游戏与屏保会话均可使用，所有方法均无前置要求。库表为只读。

> `binary_*` 方法的格式串（`fmt`）语法与 Lua 5.4 `string.pack` / `string.unpack` 兼容，支持字节序、整数/浮点/字符串等类型说明符。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `serialization.json_encode(t)` | 将 Lua 表编码为 JSON 字符串 |
| `serialization.json_decode(s)` | 将 JSON 字符串解码为 Lua 表 |
| `serialization.csv_encode(t)` | 将二维数组编码为 CSV 字符串 |
| `serialization.csv_decode(s)` | 将 CSV 字符串解码为二维数组 |
| `serialization.yaml_encode(t)` | 将 Lua 表编码为 YAML 字符串 |
| `serialization.yaml_decode(s)` | 将 YAML 字符串解码为 Lua 表 |
| `serialization.toml_encode(t)` | 将 Lua 表编码为 TOML 字符串 |
| `serialization.toml_decode(s)` | 将 TOML 字符串解码为 Lua 表 |
| `serialization.ini_encode(t)` | 将 Lua 表编码为 INI 字符串 |
| `serialization.ini_decode(s)` | 将 INI 字符串解码为 Lua 表 |
| `serialization.xml_encode(t)` | 将 Lua 表编码为 XML 字符串 |
| `serialization.xml_decode(s)` | 将 XML 字符串解码为 Lua 表 |
| `serialization.binary_pack(fmt, ...)` | 按格式串打包数据为二进制字符串 |
| `serialization.binary_unpack(fmt, s, pos)` | 按格式串从二进制字符串解包数据 |
| `serialization.binary_packsize(fmt)` | 返回按格式打包所需的总字节数 |
