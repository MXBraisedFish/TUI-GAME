# encoding 库

## 基本库说明

`encoding` 提供字符串与二进制数据的编码转换：Base64、URL 百分号编码、十六进制。游戏与屏保会话均可使用，所有方法均无前置要求。库表为只读。

> Lua 字符串可承载任意字节（`0..255`），因此各方法入参均可为二进制数据。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `encoding.base64_encode(s)` | 将字符串或二进制数据编码为 Base64 字符串 |
| `encoding.base64_decode(s)` | 将 Base64 字符串解码为原始字符串 |
| `encoding.url_encode(s)` | 将字符串编码为 URL 安全格式（百分号编码） |
| `encoding.url_decode(s)` | 将 URL 编码字符串解码为原始字符串 |
| `encoding.hex_encode(s)` | 将字符串编码为十六进制字符串 |
| `encoding.hex_decode(s)` | 将十六进制字符串解码为原始字符串 |
