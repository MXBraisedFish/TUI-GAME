# i18n 库

## 基本库说明

`i18n` 提供程序语言文本的加载与查询：`create` 单例加载语言命名空间表，`get_key` 按键值查询，`get_language_code` 查询当前语言代码，`reload` 重载语言。库表为只读。

- `create` 与 `reload` 为**异步**：调用后不直接返回结果，宿主处理完成后通过类型为 `i18n` 的事件（`HandleEvent`）返回，事件 `data` 中含 `kind`、`ok`、`message`、`language_code`、`callback_language_code`。
- `get_key` 与 `get_language_code` 为同步方法，直接返回结果。
- 语言文件位于语言目录（`assets/language/<language_code>/`）下的 JSON 文件：每个 JSON 文件对应一个命名空间，文件名（不含 `.json` 扩展名）即命名空间名。
- 一个脚本仅能创建一个实例（单例），重复调用 `create` 被忽略（保持首次实例，不再发送事件）。
- `reload` 不会复用 `create` 时传入的参数，需要重新传入；未先调用 `create` 时直接调用 `reload` 会被忽略（不发送事件）。

## 目录

### 常量

本库无常量。

### 方法

| 方法名 | 说明 |
| ------ | ---- |
| `i18n.create{...}` | 创建 i18n 实例（单例），加载语言命名空间表 |
| `i18n.get_key{...}` | 获取指定命名空间下的键值 |
| `i18n.get_language_code()` | 获取当前程序使用的语言代码 |
| `i18n.reload{...}` | 重新加载当前语言 |

## 方法

### `create`

- **方法作用**：创建 i18n 实例（单例），扫描语言目录加载 JSON 文件形成命名空间表。
- **方法要求**：一个脚本仅能创建一个实例，重复调用被忽略（保持首次实例，不再发送事件）。加载成功后通过 `i18n` 事件传递回调信息；若文件不存在或扫描出错，生成空表。
- **方法参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 | 额外补充 |
| ------ | ---- | ---- | ------ | ---- | -------- |
| `language_code` | string | 否 | 程序语言代码 | 强制指定加载的语言 ID | 传入 `nil` 使用默认 |
| `callback_language_code` | string | 否 | `"en_us"` | 备用语言 ID | 供 `get_key` 查找失败时回退使用 |

- **方法返回**：无直接返回值（异步）。完成后 `HandleEvent` 收到 `i18n` 事件：

| 字段                       | 类型      | 说明                             |
| ------------------------ | ------- | ------------------------------ |
| `kind`                   | string  | 恒为 `"created"`                 |
| `ok`                     | boolean | 是否加载成功（含空表情况，如语言目录或文件不存在）      |
| `message`                | string  | 加载信息，成功为 `"loaded"`，扫描出错时为错误描述 |
| `language_code`          | string  | 实际加载的语言代码                      |
| `callback_language_code` | string  | 备用语言代码                         |

### `get_key`

- **方法作用**：获取指定命名空间下的键值。
- **方法要求**：若命名空间或键不存在，尝试从 callback 语言表查找；若仍不存在，返回缺省标识。
- **方法参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 | 额外补充 |
| ------ | ---- | ---- | ------ | ---- | -------- |
| `name_space` | string | 是 | — | 命名空间名称 | 对应 JSON 文件名 |
| `key` | string | 是 | — | 键名 | 对应 JSON 文件中的键 |

- **方法返回**：

| 返回值名    | 类型     | 说明  | 额外补充                                       |
| ------- | ------ | --- | ------------------------------------------ |
| `value` | string | 键值  | 不存在时返回 `"[缺少 i18n 键：{value:missing_key}]"` |

### `reload`

- **方法作用**：重新加载当前语言。
- **方法要求**：需先调用 `create`，未调用过 `create` 时调用被忽略（不发送事件）。不会复用 `create` 时传入的参数，需重新传入，否则使用默认值。加载成功后通过 `i18n` 事件传递回调信息；若文件不存在或扫描出错，生成空表。
- **方法参数**：

| 参数名                      | 类型     | 必填  | 默认值       | 说明           | 额外补充                  |
| ------------------------ | ------ | --- | --------- | ------------ | --------------------- |
| `language_code`          | string | 否   | 程序语言代码    | 强制指定加载的语言 ID | 传入 `nil` 使用默认         |
| `callback_language_code` | string | 否   | `"en_us"` | 备用语言 ID      | 供 `get_key` 查找失败时回退使用 |

## 使用示例

```lua
-- 创建 i18n 实例（单例），加载指定语言
i18n.create{
  language_code = "zh_cn",          -- 可选，默认使用程序语言代码
  callback_language_code = "en_us", -- 可选，默认 "en_us"
}
-- 结果通过 i18n 事件返回（data.kind == "created"）

-- 查询键值
local title = i18n.get_key{ name_space = "home", key = "title" }
-- 未找到时返回 "???home.title"

-- 查询当前语言代码
local code = i18n.get_language_code()  -- "zh_cn"

-- 在 HandleEvent 中接收 create / reload 结果
function HandleEvent(event)
  if event.type == "i18n" then
    local data = event.data
    -- data.kind == "created" | "reloaded"
    -- data.ok / data.message / data.language_code / data.callback_language_code
    if data.ok then
      -- 语言加载成功，此后可安全调用 get_key
    end
  end
end

-- 重载语言（不会复用 create 的值，需重新传参）
i18n.reload{
  language_code = "zh_cn",
  callback_language_code = "en_us",
}
-- 结果通过 i18n 事件返回（data.kind == "reloaded"）
```
