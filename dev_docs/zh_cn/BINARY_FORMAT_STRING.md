# Lua 二进制格式化字符串规范

## 前言

二进制格式化字符串作为二进制数据包核心参数，用于精确描述如何在 Lua 值与原始字节流之间进行双向转换。本文档旨在为开发者提供一份结构清晰、查阅便捷的权威语法速查手册。

## 字节序控制

### 语法

| 符号 | 作用         |
| ---- | ------------ |
| `<`  | 小端编码     |
| `>`  | 大端编码     |
| `=`  | 跟随系统默认 |

### 示例

```lua
-- 强制小端序存储 0x12345678（4字节无符号整数）
local le_data = string.pack("<I4", 0x12345678)

-- 强制大端序存储同一数值
local be_data = string.pack(">I4", 0x12345678)

-- 使用本地序（通常等同于 < 或 >）
local native_data = string.pack("=I4", 0x12345678)
```

## 对齐控制

### 语法

| 符号  | 作用                           |
| ----- | ------------------------------ |
| `!n`  | 设置最大对齐值                 |
| `Xop` | 按指定选项规则进行对齐的空占位 |

### 额外补充

- 符号 `!n` 中的

### 作用

`!n` 用于设置全局最大对齐字节数（`n` 必须为 2 的幂，如 1、2、4、8）。打包时，Lua 会在当前写入位置自动填充空字节，确保下一个数据项的起始偏移地址为 `n` 的整数倍；解包时则自动跳过填充字节。`Xop` 是一个空操作符，仅用于在此处插入一次对齐行为（对齐方式由 `op` 选项决定，`op` 本身不产生数据），常用于精确控制特定字段的对齐边界。

### 示例

```lua
-- 设置4字节全局对齐：在 'c1' 后自动填充3个空字节，以确保接下来的 'i4' 位于4的倍数偏移
local aligned_data = string.pack("!4 c1 i4", "A", 100)

-- 使用 X 强制在当前插入点按4字节对齐（假设此前偏移不对齐）
local manual_align = string.pack("c1 Xi4 i4", "A", 100)
```

## 三、原生整数类型（C 语言映射）

### 标准语法

- 有符号：`b`, `h`, `i`, `l`, `j`
- 无符号：`B`, `H`, `I`, `L`, `J`

### 作用

直接映射至当前 C 编译器环境下的原生整数尺寸（`char`、`short`、`int`、`long`、`lua_Integer`）。其中小写代表有符号，大写代表无符号。由于各平台（如 32 位与 64 位系统）中 `long` 和 `int` 尺寸可能不同，此类选项适合单机或已知环境的内部存储，跨平台传输时建议优先使用固定尺寸类型。

### 示例

```lua
-- 打包一个有符号 char(-1) 和一个无符号 char(255)，二者在二进制表示上通常相同
local int_data = string.pack("b B", -1, 255)

-- 打包本地 int 和 long 类型
local native_pack = string.pack("i l", 12345, 67890)
```

## 四、固定尺寸整数类型

### 标准语法

- 有符号：`i[n]`
- 无符号：`I[n]`

### 作用

精确指定一个整数的字节宽度为 `n`（`n` 取值范围为 1 至 16）。此类型不依赖任何 C 语言环境，保证了在不同架构和编译器下均具有一致的二进制尺寸，是构建跨平台二进制协议的首选整数方案。`n` 省略时无效，必须显式给出数字。

### 示例

```lua
-- 打包一个2字节有符号整数（范围 -32768 ~ 32767）
local i16 = string.pack("i2", -32768)

-- 打包一个8字节无符号整数（范围 0 ~ 2^64-1）
local u64 = string.pack("I8", 18446744073709551615)

-- 混合使用不同尺寸
local mixed = string.pack("i1 I3 i4", -1, 65535, 123456)
```

## 五、浮点数类型

### 标准语法

- `f`
- `d`
- `n`

### 作用

用于序列化浮点数值。`f` 映射至 C 语言的 `float`（通常为 4 字节），`d` 映射至 `double`（通常为 8 字节），`n` 映射至 Lua 内部使用的 `lua_Number` 类型（默认为 `double`，但在某些嵌入式版本中可能为 `float`）。与整数类似，`f` 和 `d` 的具体尺寸和表示法（如是否遵循 IEEE 754）取决于本地 C 实现。

### 示例

```lua
-- 打包单精度和双精度浮点数
local floats = string.pack("f d", 1.2345, 9.8765e10)

-- 使用 Lua 内部浮点数类型
local lua_num = string.pack("n", math.pi)
```

## 六、字符串类型

### 标准语法

- `c[n]`
- `z`
- `s[n]`

### 作用

提供三种不同的字符串处理模式。`c[n]` 表示固定长度的字符串，`n` 指定字节数，若字符串过短则自动补零（`\0`），过长则截断；若省略 `n` 则默认为 1。`z` 表示以空字符（`\0`）结尾的 C 风格字符串，打包时自动追加终止符，解包时读取直至遇到 `\0`。`s[n]` 采用“长度-数据”结构，先将字符串的字节长度作为一个 `n` 字节的**无符号整数**写入，随后写入字符串内容，默认 `n` 为 `size_t` 尺寸；该格式非常适合解析网络数据包中的变长字段。

### 示例

```lua
-- 固定3字节字符串，若不足3字节则补 0x00
local fixed = string.pack("c3", "Hi")  -- 实际内容为 'H', 'i', '\0'

-- 以 '\0' 结尾的字符串
local null_term = string.pack("z", "Lua")  -- 末尾自动附加 '\0'

-- 显式长度前缀：使用1字节无符号整数存储长度，随后跟内容
local prefixed = string.pack("s1", "Hello")  -- 结果为 0x05, 'H','e','l','l','o'
```

## 七、特殊填充与空白符

### 标准语法

- `x`
- `' '` （空格字符）

### 作用

`x` 表示一个空字节（0x00），在打包时向字节流中插入一个占位填充字节，在解包时则忽略该位置的一个字节，常用于字段间的固定分隔或预留扩展位。空格字符（`' '`）在格式化字符串中不具有任何实际操作效果，完全被解析器忽略，仅用于提高长格式字符串的可读性，例如将不同功能区块隔开。

### 示例

```lua
-- 在两个整数之间插入一个空字节填充
local padded = string.pack("i4 x i4", 0xAABBCCDD, 0x11223344)

-- 使用空格分隔不同语义区块，方便阅读，对结果无影响
local readable = string.pack("i2 s2 i4", 1, "AB", 2)  -- 此处无空格
local readable_with_space = string.pack("i2 s2 i4", 1, "AB", 2) -- 等价写法，无空格隔开也无妨
-- 实际仅在字符串字面量中可加空格：string.pack("i2  s2  i4", ...) 中间的多个空格会被忽略
```
