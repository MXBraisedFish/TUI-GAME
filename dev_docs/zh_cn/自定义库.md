# 库 API 参考

## draw 库

**作用：** 基本的文本绘制与区域操作。

### 常量

该库无公开常量。

### 方法

#### `text`

将文本绘制在指定坐标。

**参数**

| 参数名               | 类型                 | 必填  | 默认值             | 说明                      | 额外补充                             |
| ----------------- | ------------------ | --- | --------------- | ----------------------- | -------------------------------- |
| `x`               | int                | 是   | -               | 横坐标                     | -                                |
| `y`               | int                | 是   | -               | 纵坐标                     | -                                |
| `text`            | string             | 是   | -               | 要绘制的文本                  | -                                |
| `fg`              | string/const-color | 否   | `color.NONE`    | 前景颜色                    | -                                |
| `bg`              | string/const-color | 否   | `color.NONE`    | 背景颜色                    | -                                |
| `align`           | const-align        | 否   | `align.LEFT`    | 换行对齐方向                  | 仅支持水平对齐参数                        |
| `auto_warp`       | nil/boolean        | 否   | `true`          | 自动换行                    | nil 表示禁止所有换行操作，false 表示仅显式换行（\n） |
| `word_wrap`       | boolean            | 否   | `true`          | 是否智能整词换行                | -                                |
| `max_height`      | int/const-math     | 否   | `math.INFINITE` | 最大高度                    | 大于 0 的正整数                        |
| `max_width`       | int/const-math     | 否   | `math.INFINITE` | 最大宽度                    | 大于 0 的正整数                        |
| `overflow_marker` | string             | 否   | `"..."`         | 溢出内容省略标记文本              | 支持空字符串                           |
| `rich_params`     | nil/table          | 否   | `nil`           | 富文本 `{key:params}` 值替换表 | -                                |
| `bold`            | boolean            | 否   | `false`         | 加粗                      | -                                |
| `italic`          | boolean            | 否   | `false`         | 斜体                      | -                                |
| `underline`       | boolean            | 否   | `false`         | 下划线                     | -                                |
| `strike`          | boolean            | 否   | `false`         | 删除线                     | -                                |
| `blink`           | boolean            | 否   | `false`         | 闪烁                      | -                                |
| `reverse`         | boolean            | 否   | `false`         | 反色                      | -                                |
| `hidden`          | boolean            | 否   | `false`         | 隐藏                      | -                                |
| `dim`             | boolean            | 否   | `false`         | 变暗                      | -                                |
| `text_mode`       | const              | 否   | `string.AUTO`   | 文本解析模式                  | -                                |
| `slice_layer`     | string             | 否   | `"base"`        | 要绘制的切片图层 ID             | -                                |

**返回值**  
无

---

#### `fill_rect`

填充一个矩形区域。

**参数**

| 参数名           | 类型           | 必填  | 默认值          | 说明          | 额外补充         |
| ------------- | ------------ | --- | ------------ | ----------- | ------------ |
| `x`           | int          | 是   | -            | 横坐标         | -            |
| `y`           | int          | 是   | -            | 纵坐标         | -            |
| `width`       | int          | 是   | -            | 矩形宽度        | 大于 0 的正整数    |
| `height`      | int          | 是   | -            | 矩形高度        | 大于 0 的正整数    |
| `char`        | nil/char     | 否   | nil          | 要填充的字符      | 仅支持宽度为 1 的字符 |
| `fg`          | string/const | 否   | `color.NONE` | 前景颜色        | -            |
| `bg`          | string/const | 否   | `color.NONE` | 背景颜色        | -            |
| `slice_layer` | string       | 否   | `"base"`     | 要绘制的切片图层 ID | -            |

**返回值**  
无

---

#### `stroke_rect`

绘制一个矩形边框。

**参数**

| 参数名           | 类型                   | 必填  | 默认值          | 说明          | 额外补充      |
| ------------- | -------------------- | --- | ------------ | ----------- | --------- |
| `x`           | int                  | 是   | -            | 横坐标         | -         |
| `y`           | int                  | 是   | -            | 纵坐标         | -         |
| `width`       | int                  | 是   | -            | 矩形宽度        | 大于 0 的正整数 |
| `height`      | int                  | 是   | -            | 矩形高度        | 大于 0 的正整数 |
| `fg`          | string/const-color   | 否   | `color.NONE` | 前景颜色        | -         |
| `bg`          | string/const-color   | 否   | `color.NONE` | 背景颜色        | -         |
| `border_char` | nil/table/const-char | 否   | `char.LINE`  | 矩形边框字符      |           |
| `slice_layer` | string               | 否   | `"base"`     | 要绘制的切片图层 ID | -         |

`border_char`：

```lua
{
  top          = style.Line.top,          -- nil/char/const-char（仅支持宽度为 1 的字符）
  left_top     = style.Line.left_top,     -- nil/char/const-char（仅支持宽度为 1 的字符）
  left         = style.Line.left,         -- nil/char/const-char（仅支持宽度为 1 的字符）
  left_bottom  = style.Line.left_bottom,  -- nil/char/const-char（仅支持宽度为 1 的字符）
  bottom       = style.Line.bottom,       -- nil/char/const-char（仅支持宽度为 1 的字符）
  right_bottom = style.Line.right_bottom, -- nil/char/const-char（仅支持宽度为 1 的字符）
  right        = style.Line.right,        -- nil/char/const-char（仅支持宽度为 1 的字符）
  right_top    = style.Line.right_top,    -- nil/char/const-char（仅支持宽度为 1 的字符）
}
```

**返回值**  
无

---

#### `erase_rect`

完全擦除一片区域的全部内容。

**参数**

| 参数名           | 类型     | 必填  | 默认值      | 说明          | 额外补充      |
| ------------- | ------ | --- | -------- | ----------- | --------- |
| `x`           | int    | 是   | -        | 横坐标         | -         |
| `y`           | int    | 是   | -        | 纵坐标         | -         |
| `width`       | int    | 是   | -        | 矩形宽度        | 大于 0 的正整数 |
| `height`      | int    | 是   | -        | 矩形高度        | 大于 0 的正整数 |
| `slice_layer` | string | 否   | `"base"` | 要绘制的切片图层 ID | -         |

**返回值**  
无

---

#### `render`

请求调用一次Render回调。

**参数**
无

**返回值**  
无

## color 库

**作用：** 提供颜色常量和格式化转换。

### 常量

| 常量名                        | 说明                           |
| ----------------------------- | ------------------------------ |
| `BLACK`                       | 黑色                           |
| `RED`                         | 红色                           |
| `GREEN`                       | 绿色                           |
| `YELLOW`                      | 黄色                           |
| `BLUE`                        | 蓝色                           |
| `MAGENTA`                     | 品红                           |
| `CYAN`                        | 青色                           |
| `GRAY` / `GREY`               | 灰色（对应 bright_black）      |
| `BRIGHT_GRAY` / `BRIGHT_GREY` | 淡灰色/亮灰（对应 dark_white） |
| `BRIGHT_RED`                  | 亮红                           |
| `BRIGHT_GREEN`                | 亮绿                           |
| `BRIGHT_YELLOW`               | 亮黄                           |
| `BRIGHT_BLUE`                 | 亮蓝                           |
| `BRIGHT_MAGENTA`              | 亮品红                         |
| `BRIGHT_CYAN`                 | 亮青                           |
| `WHITE`                       | 白色（对应 bright_white）      |
| `NONE`                        | 无颜色（默认色）               |
| `TRANSPARENT`                 | 透明（仅适合 `bg` 参数）       |

### 方法

#### `rgb`

将三个通道值组合为标准的 `rgb(r,g,b)` 字符串。

**参数**

| 参数名 | 类型  | 必填  | 默认值 | 说明   | 额外补充    |
| --- | --- | --- | --- | ---- | ------- |
| `r` | int | 是   | -   | 红色通道 | 0 - 255 |
| `g` | int | 是   | -   | 绿色通道 | 0 - 255 |
| `b` | int | 是   | -   | 蓝色通道 | 0 - 255 |

**返回值**  
`string` – 格式化的颜色字符串，例如 `"rgb(255,0,0)"`

---

#### `hex`

将三个通道值组合为标准的十六进制颜色字符串。

**参数**

| 参数名 | 类型  | 必填  | 默认值 | 说明   | 额外补充    |
| --- | --- | --- | --- | ---- | ------- |
| `r` | int | 是   | -   | 红色通道 | 0 - 255 |
| `g` | int | 是   | -   | 绿色通道 | 0 - 255 |
| `b` | int | 是   | -   | 蓝色通道 | 0 - 255 |

**返回值**  
`string` – 格式化的颜色字符串，例如 `"#ff0000"`

## align 库

**作用：** 辅助计算对齐坐标。

### 常量

| 常量名                 | 说明                       |
| ------------------- | ------------------------ |
| `AUTO`              | 自动对齐（仅适合支持 AUTO 的参数）     |
| `LEFT`              | 水平左对齐                    |
| `HORIZONTAL_CENTER` | 水平居中对齐                   |
| `RIGHT`             | 水平右对齐                    |
| `TOP`               | 垂直顶对齐                    |
| `VERTICAL_CENTER`   | 垂直居中对齐                   |
| `BOTTOM`            | 垂直底对齐                    |
| `CENTER`            | 水平/垂直完全居中（自动判断是水平还是垂直对齐） |

### 方法

#### `resolve_x`

根据水平对齐方式计算内容绘制的起始 X 坐标。

**参数**

| 参数名           | 类型     | 必填  | 默认值         | 说明                     | 额外补充      |
| ------------- | ------ | --- | ----------- | ---------------------- | --------- |
| `width`       | int    | 是   | -           | 内容宽度                   | 大于 0 的正整数 |
| `align`       | const  | 是   | -           | 水平对齐方式                 | 仅支持水平对齐参数 |
| `offset`      | int    | 否   | `0`         | X 轴偏移值                 | -         |
| `x`           | int    | 否   | 取决于 `align` | 对齐相对的 X 轴位置，默认值随对齐方式变化 | -         |
| `slice_layer` | string | 否   | `"base"`    | 要计算的切片图层 ID            | -         |

**返回值**  
`int` – 内容绘制起始 X 坐标

---

#### `resolve_y`

根据垂直对齐方式计算内容绘制的起始 Y 坐标。

**参数**

| 参数名           | 类型     | 必填  | 默认值         | 说明                     | 额外补充      |
| ------------- | ------ | --- | ----------- | ---------------------- | --------- |
| `height`      | int    | 是   | -           | 内容高度                   | 大于 0 的正整数 |
| `align`       | const  | 是   | -           | 垂直对齐方式                 | 仅支持垂直对齐参数 |
| `offset`      | int    | 否   | `0`         | Y 轴偏移值                 | -         |
| `y`           | int    | 否   | 取决于 `align` | 对齐相对的 Y 轴位置，默认值随对齐方式变化 | -         |
| `slice_layer` | string | 否   | `"base"`    | 要计算的切片图层 ID            | -         |

**返回值**  
`int` – 内容绘制起始 Y 坐标

---

#### `resolve_rect`

根据水平和垂直对齐方式同时计算 X、Y 起始坐标。

**参数**

| 参数名                | 类型     | 必填  | 默认值      | 说明          | 额外补充      |
| ------------------ | ------ | --- | -------- | ----------- | --------- |
| `width`            | int    | 是   | -        | 内容宽度        | 大于 0 的正整数 |
| `height`           | int    | 是   | -        | 内容高度        | 大于 0 的正整数 |
| `horizontal_align` | const  | 是   | -        | 水平对齐方式      | 仅支持水平对齐参数 |
| `vertical_align`   | const  | 是   | -        | 垂直对齐方式      | 仅支持垂直对齐参数 |
| `offset_x`         | int    | 否   | `0`      | X 轴偏移值      | -         |
| `offset_y`         | int    | 否   | `0`      | Y 轴偏移值      | -         |
| `x`                | int    | 否   | 取决于水平对齐  | 对齐相对的 X 轴位置 | -         |
| `y`                | int    | 否   | 取决于垂直对齐  | 对齐相对的 Y 轴位置 | -         |
| `slice_layer`      | string | 否   | `"base"` | 要计算的切片图层 ID | -         |

**返回值**（多值）

- `x` (int) – 内容绘制起始 X 坐标
- `y` (int) – 内容绘制起始 Y 坐标

## measurement 库

**作用：** 辅助计算内容的宽高。

### 方法

#### `get_text_size`

自动识别文本类型并获取其宽度与高度，会截取 `f%` 前缀。

**参数**

| 参数名               | 类型          | 必填  | 默认值             | 说明     | 额外补充                             |
| ----------------- | ----------- | --- | --------------- | ------ | -------------------------------- |
| `text`            | string      | 是   | -               | 要测量的文本 | -                                |
| `align`           | const-align | 否   | `align.LEFT`    | 换行对齐方向 | 仅支持水平对齐参数                        |
| `auto_warp`       | nil/boolean | 否   | `true`          | 自动换行   | nil 表示禁止所有换行操作，false 表示仅显式换行（\n） |
| `word_wrap`       | boolean     | 否   | `true`          | 智能整词换行 | -                                |
| `max_height`      | int/const   | 否   | `math.INFINITE` | 最大高度   | 大于 0 的正整数                        |
| `max_width`       | int/const   | 否   | `math.INFINITE` | 最大宽度   | 大于 0 的正整数                        |
| `overflow_marker` | string      | 否   | `"..."`         | 溢出省略标记 | 支持空字符串                           |
| `rich_params`     | table       | 否   | `nil`           | 富文本替换表 | -                                |
| `text_mode`       | const       | 否   | `string.AUTO`   | 文本解析模式 | -                                |

**返回值**（多值）

- `width` (int) – 内容宽度
- `height` (int) – 内容高度

---

#### `get_text_width`

获取文本宽度，会截取 `f%` 前缀。参数同 `get_text_size`。

**返回值**  
`int` – 内容宽度

---

#### `get_text_height`

获取文本高度，会截取 `f%` 前缀。参数同 `get_text_size`。

**返回值**  
`int` – 内容高度

---

## string 库（扩展）

**作用：** 对原始 `string` 库的扩展。原始库的常量和方法均保留，此处仅列出新增/统一的部分。

### 常量

| 常量名       | 说明                                               |
| ------------ | -------------------------------------------------- |
| `AUTO`       | 自动判别普通字符串或富文本（会自动截取 `f%` 前缀） |
| `PLAIN_TEXT` | 强制以普通字符串解析（不截取 `f%` 前缀）           |
| `RICH_TEXT`  | 强制以富文本字符串解析（不截取 `f%` 前缀）         |

### 方法

#### `rich_text_to_plain_text`

将富文本内容中的样式标签移除，并替换所有参数，返回纯文本字符串。

**参数**

| 参数名            | 类型      | 必填  | 默认值    | 说明                      |
| -------------- | ------- | --- | ------ | ----------------------- |
| `text`         | string  | 是   | -      | 要转换的富文本字符串              |
| `rich_params`  | table   | 否   | `nil`  | 富文本 `{key:params}` 值替换表 |
| `strip_header` | boolean | 否   | `true` | 是否自动去除开头的 `f%` 标识头      |

**返回值**
